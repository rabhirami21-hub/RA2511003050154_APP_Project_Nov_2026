Robust Chaos-Driven Cryptosystem for Telemedicine Image Privacy

Encrypt a medical image in your browser with a 2D Hénon-map cipher: chaotic permutation (confusion) followed by XOR with a chaotic key image (diffusion). Everything runs locally; no image leaves your device.

How it works

Secret key (a, b, x₀, y₀)→Hénon map, N + 1000 steps→X: sort index = permutation+Y: ⌊|y|·10¹⁴⌋ mod 256 = key image
Plain image→Confusion: C[i] = I[P[i]]→Diffusion: E[i] = C[i] ⊕ K[i]→Cipher image

Map: xₙ₊₁ = 1 − a·xₙ² + yₙ, yₙ₊₁ = b·xₙ. The first 1000 iterations are discarded. Decryption regenerates the same series, XORs again (self-inverse) and inverts the permutation, so recovery is pixel-exact. Default key: a = 1.4, b = 0.3, x₀ = 0.1, y₀ = 0.3.

Strengths
  • Flat histogram, entropy ≈ 7.999 bits
  • Spatial correlation removed (|r| < 0.005)
  • Key error of 10⁻¹⁵ gives ~99.6 % wrong pixels
  • Lossless; stages are swappable (OOP design)
Limitations and future work
  • Keystream ignores the plaintext, so NPCR is only ~0.0004 %
  • Key reuse leaks the XOR of two permuted plaintexts
  • Next: derive x₀ from an image hash, permute–diffuse–permute rounds, NIST SP 800-22
